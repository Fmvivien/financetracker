# Finance Tracker

A Spring Boot REST API for managing and filtering corporate loan products, built as a hands-on project during my Java backend developer training. It combines my 10 years of corporate banking experience with modern backend development.

**Tech stack:** Java 21, Spring Boot 3, Spring Data JPA / Hibernate, MySQL, JUnit 5, Mockito, Maven

The project follows a layered architecture (Controller, Service, Repository) with DTOs, and the database password is kept outside the code in an environment variable.
Product names refer to real Hungarian financing programs; the amounts and parameters are simplified sample values for demonstration, not official or current offers.

The project is under active development.
